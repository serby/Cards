# Brazilian Portuguese (pt-BR)

## Register

- Brazilian usage only, never European: câmera (not câmara), tela (not ecrã), salvar (not guardar), marrom (not castanho), gerunds ("Carregando", "Buscando").
- Address the user as "você", as Apple does. Possessives take no article: "Sua localização", "seus cartões". Instructions use Apple's imperative: "Digite", "Selecione", "Aponte", "Escaneie".
- VoiceOver hints are third person present: "Abre o cartão para edição".

## Apple terms

Ajustes (Settings), Tela Bloqueada (Lock Screen), Serviços de Localização, Notificações, Câmera, Editar, OK (Done and OK), Cancelar, Apagar (Delete, never "Excluir"), Adicionar, Salvar, Buscar, Exportar, Importar, Área de Transferência, alfinete (map pin), Ativado and Desativado.

## Glossary decisions

- card: cartão; loyalty card: cartão de fidelidade; membership card: cartão de sócio.
- barcode: código de barras; code: código; barcode type: tipo de código de barras.
- The user scanning with the camera: escanear. The shop's scanner reading the screen: leitura, ler. Barcode scanner: leitor de código de barras.
- location (titles, buttons): Local, Locais; place (sentences): lugar.
- Brightness Boost: Brilho Máximo, capitalised everywhere as a feature name ("Brilho Máximo ativado").
- postcode: CEP. radius: raio. Teal: Verde-azulado. Graphite: Grafite. Brown: Marrom.
- QR Code, EAN-13 and the other format names stay unchanged.

## Capitalisation and punctuation

- Buttons, titles, menu items and headings use Apple pt-BR title case: capitalise nouns, verbs and adjectives, keep articles and prepositions lower case ("Apagar Todos os Cartões", "Mover para Cima").
- Labels, hints, messages and announcements use sentence case.
- Quotation marks: “ ”. e.g.: "ex.:".
- Permission prompts are full sentences ending with a full stop.

## Pitfalls

- Distances need "a": "A 350 m de Westway", never "350 m de Westway".
- Arguments that can be a list of names need number-neutral wording: "Você apagou %@".
- Put long codes last in announcements: "EAN-13 escaneado: %2$@".
- Plurals: "one" covers 0 and 1 (Brazilian norm: singular below 2); "many" is exact millions and takes "de": "%lld de cartões".
- Errors: "Não foi possível…", not "Falha ao…".
- Never write a unit; distances arrive through the placeholder.
