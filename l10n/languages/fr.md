# French (France)

## Register

Address the user as "vous", as Apple's French iOS does. Imperative for instructions and for hints that ask the user to act ("Saisissez…", "Choisissez…"), third-person present for hints that describe a result ("Ouvre la carte pour la modifier"), infinitive in field placeholders ("Saisir le nom"). Sentence case for titles and buttons ("Ajouter une carte", "Tout supprimer"). Accent capitals: "À %@", "Épingle sur le plan".

## Apple terms

Réglages (Settings), écran verrouillé (Lock Screen), Service de localisation (Location Services), Notifications, appareil photo (Camera), Modifier (Edit), OK (Done and OK), Annuler, Supprimer, Enregistrer (Save), Exporter, Importer, Coller, presse-papiers, Luminosité, scanner (the verb), code QR. A map is a "plan" (as in Apple's Plans app), never "carte", and its pin is an "épingle". Switch values are "Activé" and "Désactivé".

## Glossary

- card: carte (carte de fidélité, carte d’adhésion); the list is "Cartes".
- barcode: code-barres, plural codes-barres. code: code. Barcode Type: Type de code-barres.
- location and place: lieu, lieux, in titles and sentences alike.
- Brightness Boost: Luminosité renforcée, for the setting, the button and the announcements ("Luminosité renforcée activée").
- postcode: code postal. radius: rayon ("Rayon de %@").
- Colours: Rouge, Orange, Jaune, Vert, Sarcelle (Teal), Bleu, Indigo, Violet (Purple), Rose, Marron, Graphite, Par défaut.

## Typography

- Apostrophe ’ (U+2019), never '.
- A no-break space (U+00A0) before : ; ? ! and inside « »: "Code de la carte : %@", "« %@ »". Never “ ”.
- "p. ex." with a no-break space after "p.".
- Distances arrive through placeholders; never write a unit.

## Plurals

"one" covers 0 and 1. "many" is for exact millions and takes "de": "%lld de cartes".

## Pitfalls

- Agreement: carte is feminine ("Créée le %@", "%lld carte importée"); lieu is masculine ("Ajouté : %@").
- Before a place name use "à" and no article: "Vous êtes à %@".
- A hint for a toggle covers both directions: "Active ou désactive…".
- Permission prompts are complete sentences ending in a full stop.
- Keep buttons short: "Rechercher", "Tout supprimer".
